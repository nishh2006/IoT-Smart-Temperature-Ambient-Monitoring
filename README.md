# IoT Environmental Telemetry & Ambient Climate Monitor

## 📌 Technical Summary
An automated telemetry system that continuously captures temperature and humidity metrics, processing data on the edge for ambient environment tracking.

## 🛠️ Architecture & Components
- **Core Controller:** ESP32 Microcontroller
- **Firmware:** Embedded C / C++ (Arduino Framework)
- **Peripherals:** DHT Temperature & Humidity Sensors, Serial Data Monitor
